# Soil-Erosion-RF-RUSLE
# Soil Erosion Modeling using RUSLE and Random Forest

This repository contains the code and sample data used in the study on soil erosion prediction.

## Contents
- Google Earth Engine (GEE) script used to generate the soil erosion map using a Random Forest model  
- Soil sample dataset, including laboratory analysis and derived RUSLE factor values (training and testing datasets)  

## Data Availability
Only a subset of the data is provided in this repository. Full datasets are available from the corresponding author upon reasonable request.

## Requirements
- Google Earth Engine account  
- Basic knowledge of JavaScript (for GEE)

## Notes
All datasets used are either publicly available or derived from publicly accessible sources.
